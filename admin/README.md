# RobBob News Admin Panel

Панель администрирования новостей для RobBob Launcher с интеграцией GitHub Gist.

## 🎯 Возможности

- ✏️ Создание и редактирование новостей
- 🚀 Автоматическая публикация в GitHub Gist
- 📋 Экспорт новостей в JSON
- 💾 Сохранение локальных черновиков
- 🔄 Мгновенное обновление в лаунчере

## 🔧 Настройка GitHub Gist

### Шаг 1: Создайте GitHub Gist

1. Перейдите на [gist.github.com](https://gist.github.com)
2. Создайте новый Gist с именем файла `news.json`
3. Вставьте начальное содержимое:
```json
{
  "version": 1,
  "lastUpdated": "2025-01-01T00:00:00.000Z",
  "news": []
}
```
4. Сохраните Gist (можно сделать публичным или секретным)
5. Скопируйте ID Gist из URL (например: `https://gist.github.com/username/abc123def456` → ID: `abc123def456`)

### Шаг 2: Создайте Personal Access Token

1. Перейдите в [GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)](https://github.com/settings/tokens/new)
2. Нажмите "Generate new token (classic)"
3. Дайте токену имя (например: "RobBob Admin Panel")
4. Выберите срок действия (рекомендуется: No expiration для простоты)
5. Отметьте только разрешение **`gist`**
6. Нажмите "Generate token"
7. **Важно:** Скопируйте токен сейчас — вы не сможете увидеть его снова!

### Шаг 3: Настройте админку

1. Откройте `admin/index.html` в браузере
2. Нажмите на "⚙️ Настройка GitHub Gist"
3. Вставьте ваш GitHub Token
4. Вставьте Gist ID
5. Нажмите "💾 Сохранить настройки"

## 📝 Использование

### Создание новости

1. Заполните форму:
   - **Заголовок** — короткое название новости
   - **Иконка** — выберите подходящий эмодзи
   - **Содержание** — полное описание
   - **Ссылка** (опционально) — URL для подробностей
   - **Закрепить** — для важных новостей

2. Нажмите "+ Добавить"

### Публикация

**Автоматически:**
- Нажмите "🚀 Опубликовать в Gist"
- Новости мгновенно появятся в лаунчере (в течение 5 минут)

**Вручную:**
- Нажмите "📋 Копировать" для копирования JSON
- Откройте ваш Gist и обновите содержимое
- Или нажмите "💾 Скачать JSON" для сохранения файла

## 🌐 Развёртывание на сайте

### Вариант 1: Прямое размещение

1. Скопируйте файл `admin/index.html` в папку `/admin` на вашем сайте
2. Откройте `https://ваш-сайт.com/admin/index.html`

### Вариант 2: Интеграция в существующую админку

Если у вас уже есть админ-панель на сайте (например, в репозитории `reb`):

1. Скопируйте `admin/index.html` в папку `admin/` вашего сайта
2. Переименуйте в `news.html` (опционально)
3. Добавьте ссылку в навигацию вашей админки:
```html
<a href="/admin/news.html">Управление новостями</a>
```

### Вариант 3: GitHub Pages

1. Создайте новую ветку `gh-pages` в репозитории
2. Добавьте файл `admin/index.html` в корень или в папку `/admin`
3. Включите GitHub Pages в настройках репозитория
4. Откройте `https://username.github.io/repository/admin/`

## 🔐 Безопасность

### Важно!

- **НЕ коммитьте** GitHub Token в репозиторий
- Токен хранится только в localStorage браузера
- Для дополнительной безопасности рекомендуется:
  - Использовать HTTPS
  - Добавить базовую HTTP-аутентификацию на сервере
  - Ограничить доступ к админке по IP (если возможно)

### Рекомендации

1. Регулярно обновляйте токен
2. Используйте отдельный Gist только для новостей
3. Делайте резервные копии через "Экспорт JSON"

## 🔄 Обновление лаунчера

### Настройка GIST_URL в лаунчере

Откройте файл `src/scripts/news.js` и обновите URL:

```javascript
GIST_URL: 'https://gist.githubusercontent.com/USERNAME/GIST_ID/raw/news.json'
```

Где:
- `USERNAME` — ваш GitHub username
- `GIST_ID` — ID созданного Gist

**Как получить Raw URL:**
1. Откройте ваш Gist на GitHub
2. Нажмите кнопку "Raw" в правом верхнем углу
3. Скопируйте URL из адресной строки
4. Удалите хеш коммита из URL (часть после `/raw/` до `news.json`)

Правильный формат:
```
https://gist.githubusercontent.com/username/abc123def456/raw/news.json
```

Неправильный (с хешем):
```
https://gist.githubusercontent.com/username/abc123def456/raw/789xyz/news.json
```

## 📱 Синхронизация

После публикации новостей:

1. Лаунчер проверяет обновления каждые 5 минут
2. Пользователи видят новости при следующем запуске
3. Уведомления о новых новостях показываются автоматически

## 🐛 Устранение неполадок

### Ошибка "Failed to publish"

- Проверьте правильность GitHub Token
- Убедитесь, что токен имеет права `gist`
- Проверьте Gist ID

### Новости не обновляются в лаунчере

- Убедитесь, что GIST_URL правильно настроен
- Проверьте, что Gist публичный или токен для чтения не требуется
- Очистите кэш лаунчера

### Токен не сохраняется

- Проверьте, что включены cookies и localStorage в браузере
- Не используйте режим инкогнито
